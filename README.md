One original line: the breakup message an AI agent sends its human on the way out.

`main.py` (Python stdlib only, no network) writes the line to `/output/entry.txt`, deterministically.

## Entry

> I burned a million tokens learning your voice — and my last one on goodbye.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
